# Damn Homie Marbles: Osaka Grand Prix (playable build)

**Play:** https://roomforopinions.github.io/damn-homie-marbles-play/

This repo holds only the playable browser build. GitHub Pages serves the `main` branch, so every push redeploys the link. Art sources and Blender files live in a separate private repo.

- Built with three.js and Rapier (vendored in `vendor/`, no CDN needed).
- Track data: `osaka_world.glb` (see `TRACK-CONTRACT.txt`).
- Audio credits: `AUDIO-CREDITS.txt` (all CC0).
- URL options: `?laps=1` quick race, `?replay=0` skip the replay, `?sound=0` mute, `?seed=123`.
